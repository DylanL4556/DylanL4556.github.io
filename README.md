# Dylan Lott - Portfolio

Personal portfolio site built with React and Vite.

Live site: https://dylanl4556.github.io/

## Running locally

Requires Node.js (LTS).

```
npm install
npm run dev
```

Then open http://localhost:5173.

To build for production:

```
npm run build
npm run preview
```

## Deployment

Pushing to `main` builds the site and deploys it to GitHub Pages through `.github/workflows/deploy.yml`.

## Structure

- `src/lib/data.js` - all site content
- `src/components/` - sidebar and page sections
- `src/index.css` - styles
